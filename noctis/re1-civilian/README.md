# NOCTIS RE1 camera test — civilian character

Real skinned civilian GLB, 7 built-in animated clips, fixed pre-rendered Piazza del Gesù concept background, Android touch portrait and landscape. Not an exact scan of the supplied person.

Civilian human and animations by Innerscene (adapted from MakeHuman), CC0: https://www.innerscene.com/tools/library/3d-parts/locomotion-collection-sam-3d-person-animated-dc23800f

One 20.9 MB GLB with baked materials, Idle_Standing, Walk_Relaxed, Walk_Brisk, Jog, Run, Walk_Carry, Sit_Stand. Materials are temporarily tinted burgundy and blue to approximate outfit. The hoodie geometry, bun, beard, spectacles and face resemblance are not yet reproduced.

3D motion must be verified with real browser screenshot before declaring the build visually acceptable.

The Piazza backdrop is a prerendered concept image, not a measured photogrammetric reconstruction. Geometric depth masks and second camera await calibration.
