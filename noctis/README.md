# NOCTIS — Napoli (PS1 test v0.5)

Temporary public Android/web test hosted under `videoblock-site/noctis/`, without modifying VideoBlock's homepage.

- `game/NOCTIS.bin`: 117,600-byte experimental *native PS1* MODE2 disc (BIOS/emulation boot **not yet runtime-verified**).
- `music/notte_ambient_zorlon_01.ogg`: browser-only Opus preview transcoded from the user-supplied MP3. The original master is preserved outside the public distribution; PS1 disc has no audio soundtrack.
- `index.html`: mobile-first EmulatorJS frontend with virtual D-pad/buttons, HTML audio loop, and error feedback.

The level is a schematic scene. No OSM geometry has been imported into the game. The character is a screen-space low-poly silhouette, not a skinned 3D character yet. This is a **diagnostic prototype**, not a verified game release.

Original development sources and scripts remain in the archived NOCTIS v0.5 development package.
